# FiniteFlow PyTools

A collection of tools using the Python interface of [FiniteFlow](https://pypi.org/project/finiteflow/).  It includes tools for using FiniteFlow with computer algebra systems that provide a Python interface, including [SymPy](https://pypi.org/project/sympy/) and [SymEngine](https://pypi.org/project/symengine/).

Install it with the command
```
pip install finiteflow-pytools[all]
```

To install only some of its dependencies, use:
```
pip install finiteflow-pytools[sympy] # install only sympy
```
or
```
pip install finiteflow-pytools[symengine] # install only symengine
```
